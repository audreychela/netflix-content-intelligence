# Netflix Content Analysis and Recommendation System

# Project Overview

This project uses data science techniques to explore Netflix movies and TV shows and investigate how machine learning can recommend similar titles.

# Project Objectives

Explore the Netflix dataset.

Clean and prepare the data.

Analyze content types, genres, release years, and other features.

Perform statistical analysis where appropriate.

Build and evaluate a content-based recommendation system.

Investigate suitable machine learning prediction tasks.

Develop an interactive application using Streamlit.
Dataset

Source: Netflix Movies and TV Shows Dataset

The dataset will be inspected before analysis and modelling.
